# 🎯 Tic-Tac-Toe Game (React + Tailwind CSS)

A modern, responsive **Tic-Tac-Toe** game built with **React** and styled using **Tailwind CSS**.  
This project is based on the official React tutorial — enhanced with animations, game history, sorting, highlights, and a clean UI.

## 🚀 Features

✅ Clean, responsive UI using **Tailwind CSS**  
✅ Displays **move history** with location `(row, col)`  
✅ Toggle between **ascending / descending** move order  
✅ Shows **“You are at move #...”** for the current move  
✅ Highlights the **three winning squares**  
✅ Displays **draw message** when no winner  
✅ Modular React components (`Board`, `Square`, `Game`)  
✅ Built entirely with **React Hooks (`useState`)**
